# 💰 Aturan Hemat Token — Wajib Diikuti

## 6 Aturan Utama

### Aturan 1: Pseudocode Dulu (Hemat 70%)
Hermes → pseudocode/logika/outline
Gemma → konversi ke kode nyata
JANGAN Hermes langsung nulis kode panjang

### Aturan 2: Batch Tugas Gemma
Kumpulkan 3-5 tugas Gemma → kerjakan sekaligus di satu sesi
Jangan gonta-ganti model setiap 1 tugas kecil

### Aturan 3: Batasi Konteks
Paste ke Gemma : maksimal 100 baris
Paste ke Hermes: maksimal 300 baris (kecuali review kritis)
JANGAN paste seluruh file — hanya bagian yang relevan

### Aturan 4: Eskalasi Bertahap
Coba Gemma dulu → gagal 2x → baru Hermes
JANGAN langsung ke Hermes untuk hal yang Gemma bisa kerjakan

### Aturan 5: Review Selektif
Hermes review HANYA: auth, payment, security, API kritis
UI biasa: review sendiri + screenshot + Gemma visual
JANGAN minta Hermes review semua file

### Aturan 6: Memori via File (Penghematan Terbesar)
Semua keputusan penting → simpan ke file .md
Sesi berikutnya: Hermes baca file → tidak perlu dijelaskan ulang
INI cara paling hemat token: tidak re-brief setiap sesi
