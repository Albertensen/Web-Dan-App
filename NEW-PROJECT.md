# Checklist Project Baru

## Fase 1 — Blueprint (Hermes, ~500 token)

- [ ] Jelaskan ide project ke Hermes: nama, tujuan, target pengguna
- [ ] Hermes output: tech stack, struktur folder, fitur MVP, urutan pengerjaan
- [ ] Simpan blueprint ke file ARCHITECTURE.md di folder project
- [ ] Tambahkan project ke Obsidian PROJECTS/_INDEX.md

## Fase 2 — Setup (Ruflo, 0 token)

- [ ] Buat folder project baru
- [ ] Init project dengan Ruflo: npx create-next-app, npm init, dll
- [ ] Setup git untuk folder project: git init + remote
- [ ] Install dependensi dasar

## Fase 3 — Coding (Gemma, GRATIS)

- [ ] Ambil fitur pertama dari blueprint
- [ ] Bagi menjadi tugas-tugas kecil (satu komponen/fungsi per tugas)
- [ ] Kerjakan tiap tugas dengan template dari .config/prompts/
- [ ] Simpan progress di TODO.md dalam folder project

## Fase 4 — Review & Deploy (Hermes, ~300 token)

- [ ] Review file kritis: auth, API, payment (jika ada)
- [ ] Fix issue yang ditemukan
- [ ] Test manual di browser
- [ ] Deploy
- [ ] Update status di Obsidian PROJECTS/_INDEX.md → 🟢 Live
